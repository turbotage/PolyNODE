# Pytorch implementation of the PolyNODE framework

This library provides a Pytorch implementation of the PolyNODE framework introduced in \[1\]. 

It includes compressing vector fields on $`\Omega^m_n`$ M-polyfolds, adapted loss functions and synthetic data generation for geometric reconstruction tasks. 

Additionally, we provide examples for how we did flow based classification tasks on the latent
representation learned from the PolyNODE autoencoder.

See \[1\] for the mathematical details and experimental results.

We are open for questions and discussions regarding the PolyNODE framework, however this module is prototype and should not be be regarded as production ready.

## Installation

To use the PolyNODE models and run the experiments clone this repository, the 
`requirements.txt` in the folder root contains all packages in the environment we used for our experiments.
There is also a `polyfold.yml` file that can be used to create the same conda environment we used via
`conda env create -f polyfold.yml`.



## Background and Conventions

The presented PolyNODE models can be used to train NODE based auto encoders on  $`\Omega^m_n`$ M-polyfolds. As subset of $`\mathbb{R}^{1+n + m}`$ these spaces are defined as $`\Omega^m_n := (-\infty, \tau_1) \times \mathbb{R}^n \times \mathbb{R}^m \cup (\tau_1, \tau_2) \times \mathbb{R}^n \times \{0\}  \cup (\tau_2, \infty) \times \mathbb{R}^n \times \mathbb{R}^m`$. Note that they have dimension jumps at $`\tau_1`$ and $`\tau_2`$. The vector field that can be generated by this library are defined on these stratified spaces. Their flows can traverse the dimensional bottlenecks and thus they can be used to train autoencoders.

Contrary to the notation $`(\tau, x, y)`$, $`\tau \in \mathbb{R}`$, $`x\in \mathbb{R}^n`$, $`y\in \mathbb{R}^m`$ in our article we adopt the following conventions for tensors representing points in and vector on $`\mathbb{R}^{1+n+m}`$: 

`x[:,0]` is the direction of the stratification; corresponding to $`\tau`$   \
`x[:,1:dim_comp+1]` are the compressing directions; corresponding to $`y`$ \
`x[:,dim_comp+1:]`  are the free directions; corresponding to $`x`$  \
`dim_comp`  corresponds to $`m`$ \
`dim_free` corresponds to $`n`$ 

## Main Contribtion

The main contribution of this library is the implementation of the vector field base class `CompVFBase` along with the derived class `CompVFReduced`. 
`CompVFBase` holds the information about the M-polyfold structure and the general structure of the functions used for the compressing vector field construction. `CompVFReduced` implements the neural networks, which we use to parametrize compressing vector fields, and the implements the compression in the compressing directions. The architecture of the neural networks is fixed. When instancing `CompVFReduced` the width of the neural networks, the constant speed in the first component, and the structure $`\Omega^m_n`$ can be passed as keyword arguments. Here `x1_compressed` corresponds to $`\tau_1`$ and `x1_decompressed` corresponds to $`\tau_2`$.
In addition to the `CompVFReduced` class there is also a `CompVF` class with the same functionality but with a more expressive neural network parametrization. In particular, `CompVF` allows for dynamics in the latent space, whereas `CompVFReduced` does not.
For ease of use, a vector field and an ODE solver can be wrapped in the `FlowModel` class, which is based on `torch.nn.Module`, whose forward method computes the flow of the vector field at time `t` starting at point `x`.

In principle this library is ODE solver agnostic but it is written with the torchdiffeq library \[2\], and in particular the fixed time step solvers, in mind.

Flowing through the dimensional bottleneck at `x1_compressed` is not guaranteed, instead the speed of the vector field in the  first component and (bounds on) the  compression rates need to be calibrated such that the flow compresses the data before it hits the stratification at `x1_compressed`. See \[1, Section 3.2\] for details.

## Example

### Reconstruction

##### *Training*

`experiment_spiral.py` implements the training of a PolyNODE autoencoder of a spiral and illustrates the functionality of the PolyNODE framework. The spiral experiments in \[1\] where performed with this script.

It is run via.
`python -m polynode.reconstruction.experiment_spiral`

The synthetic geometric data is generated by specifying a parametrization of a manifold, `SpiralND` in this case, implemented in `data_lib.py`. The input data is going be sampled from this parametrization.  Additionally, we need to specify a transformation, `shift` in this case, which generates the target data from in sampled input data. All of this is wrapped by the `DatasetSynth` class. This class also implements a `sample` method which generates the actual dataset used in the training of the neural networks.

We choose the setup $`\Omega^2_1`$ when initializing the vector field `X` as a `CompVFReduced`, making sure to choose the speed in the first component such that we flow to the target data by $`t=1`$.

We choose the loss function `LossPreprocessIsometry`, which has an isometry term that forces unwinding of the spiral, a term that that forces the flow into a position such that is can be safely compressed, and a MSE error for the target data.

![](/plot_flow.png)\
Input data (blue), target data (orange) and flowlines for a reconstruction model of a spiral with one turn.

Note that training reconstuction models for spirals with more than one turn in this setup with the specs in [1] can take more then 20 hours!

##### *Evaluation*
Trained models can be loaded and further analysed by the evaluate scripts. They calcutlate variuous error estimates and generate ilustrative plots. 
The evaluate script for the spiral models is run by

`python -m polynode.reconstruction.evaluate_spiral`

### Classification
The `classification_lib.py` module contains different vector fields that can be used to perform classification tasks.
The vector field used in the paper is the `ClassificationVF` which is a simple sequential network in both `x` and `t`.

##### *Training*
To train the classifier network, we provide the examples used in the paper for the spiral. To train this example
one can use the command

`python -m polynode.classification.classification_spiral`

To see a list of available options for instance swapping the reconstruction network used for classification and mode, run

`python -m polynode.classification.classification_spiral --help`

By default, the training script for the classifier will open a dash webservice on `127.0.0.1:8051` so that the flow of the model can be viewed as training progresses.

##### *Evaluation*
To view the final classifier and generate final plots you can run the evaluation script

`python -m polynode.classification.classification_evaluate`

and also there to list options

`python -m polynode.classification.classification_evaluate --help`
